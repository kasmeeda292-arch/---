SafeTech ป.5 — เว็บไซต์การใช้เทคโนโลยีสารสนเทศอย่างปลอดภัย

ลำดับการเรียนรู้บังคับ:
หน้าปก → คู่มือ → เข้าสู่ระบบ → แบบทดสอบก่อนเรียน → เรื่องที่ 1 → เรื่องที่ 2 → เรื่องที่ 3 → สรุปบทเรียน (1 อินโฟกราฟิก) → เกมการศึกษา → แบบทดสอบหลังเรียน → ผู้จัดทำ

หมายเหตุ:
- รูปสไลด์บทเรียนใช้ไฟล์เดิมของผู้จัดทำที่ images/lesson1, images/lesson2, images/lesson3
- แต่ละโฟลเดอร์ควรมี slide01.png ถึง slide08.png
- ภาพสรุปใช้เพียง 1 รูป: images/summary/infographic-summary.png
- รูปผู้จัดทำ: images/creator/creator-photo.png
- ระบบใช้ localStorage สำหรับบันทึกสถานะการเรียนและคะแนนในเครื่องที่เปิดเว็บไซต์
